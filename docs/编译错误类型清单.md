# RikkaHub Agents 编译错误类型清单

> 基于 CI 构建失败日志（#71-#75）整理的实战错误类型，按出现频率排序。

## 1. 资源重复定义（AAPT）
**症状：**
```
Error: Found item String/setting_provider_page_select_all more than one time
```
**原因：** strings.xml / values-zh/strings.xml 中同一 key 定义两次。
**触发场景：** 合并代码时新旧资源冲突，或手动添加时未检查已存在。
**修复：** 删除重复项；若语义不同改用新 key（如 `multi_select_all`）。
**排查：** `grep -c "key" values/strings.xml values-zh/strings.xml`，两边都应 =1。

## 2. Import 缺失（Unresolved reference）
**症状：**
```
e: file:///.../SettingMcpPage.kt:788:79 Unresolved reference 'ViewOff'
```
**原因：** 用到类/图标但未 import。hugeicons 图标**必须显式 import**（`HugeIcons.View` 不自动可用）。
**修复：** 补 `import me.rerere.hugeicons.stroke.ViewOff` 等。
**规律：** 项目内其他文件已用过的组件（如 `FilledTonalIconButton`）说明存在，报 Unresolved 基本就是缺 import。

## 3. 包名/类路径错误
**症状：**
```
e: ...OcrTransformer.kt:9:37 Unresolved reference 'TextRecognizerOptions'
```
**原因：** ML Kit 类在子包：
- 拉丁模型：`com.google.mlkit.vision.text.latin.TextRecognizerOptions`
- 中文模型：`com.google.mlkit.vision.text.chinese.ChineseTextRecognizerOptions`
**修复：** 对照官方文档确认完整包路径。

## 4. API 不存在（版本不匹配）
**症状：**
```
e: ...:62:35 Unresolved reference 'OutlinedCardDefaults'
```
**原因：** material3 中无此 API。正确为 `CardDefaults.outlinedCardBorder()`。
**修复：** 查 material3 版本实际 API，或参考项目内其他文件用法。
**规律：** 报错在 import 行自身 = 类确实不存在（不是缺 import）。

## 5. @Composable 上下文错误
**症状：**
```
e: ...:1379:21 @Composable invocations can only happen from the context of a @Composable function
```
**原因：** 常在 API 未解析的**连锁反应**中出现（lambda 被当作非 Composable）。
**修复：** 先修根因（如补 import），此错误通常随之消失。

## 6. 依赖缺失/传递依赖
**症状：**
```
Error: File google-services.json is missing
```
**原因：** 应用了 google-services 插件但无配置文件。
**修复：** 移除插件应用，或提供配置文件。

## 7. 编译环境（沙箱独有）
**症状：**
```
Illegal instruction (aidl)
```
**原因：** proot 环境 CPU 指令集问题，非代码错误。
**处理：** 以 CI 构建为准，沙箱只做代码逻辑检查。

---

## 排查流程速查
```
1. 下载 CI 日志: GET /actions/runs/{id}/logs → unzip
2. 找根因: grep "e: file://" 0_build.txt   （Kotlin 错误）
        grep "Error: Found" 0_build.txt    （资源错误）
        grep "What went wrong" 0_build.txt （任务级错误）
3. 区分: import 行报错=类不存在；使用行报错=缺 import
4. 修复后验证括号平衡，推送触发 CI
```
